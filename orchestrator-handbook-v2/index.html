Reglas de v2

  • No convertir jerarquía en upstream/downstream.
  • No mostrar “Estados” si la entidad no tiene state machine.
  • No inventar schemas, APIs, tests ni permisos.
  • Todo gap se etiqueta TBD / SPECIFICATION GAP.
  • Requisitos, tests, ADR y fuentes se separan por nivel de certeza.
  • Campos como Entradas/Salidas son parte del contrato del padre, no funciones autónomas.
