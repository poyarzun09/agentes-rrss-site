Flujos de funcionamiento

Escenarios completos de operación. Cada componente es navegable hacia su ficha técnica.

A · Tarea normal

Task Manager registra→Planner descompone y selecciona equipo→Scheduler espera recursos→Workflow ejecuta steps/gates→Context arma contexto→Agent Runtime activa rol→Model/Tool Gateway ejecutan→Verification + QA comprueban→Audit + PMO persisten→Resultado validado

B · Acción crítica

Tool call solicita acción→Permission clasifica→Policy aplica reglas→Approval crea REQUESTED→Workflow entra WAITING_APPROVAL→Usuario decide→Audit persiste→Workflow continúa o cancela

C · Error y aprendizaje

QA confirma error→Error Registry registra→RCA encuentra causa→Se corrige→Lesson Learned crea regla→Golden Task/regresión→Learning actualiza controles

D · Checkpoint/Resume

Capturar estado técnico→Persistir artifacts/decisiones/hashes→Interrumpir→Reabrir→Validar integridad/versiones→Revalidar dependencias→PMO reconstruye contexto→Workflow continúa

E · SSD externo ausente

Health detecta pérdida de TIER-1→Sistema pasa a DEGRADED→Core/PMO/DB siguen en TIER-0→Tareas dependientes quedan BLOCKED→No hay fallback silencioso→Vuelve volumen→Se valida identidad→Se reanuda
